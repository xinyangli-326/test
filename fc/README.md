# 阿里云函数计算(FC)部署说明

这个文件夹是「Trip MALL 营销内容平台」的**服务端中转**，专门用来让
「千问AI平台 Token Plan（阿里云月付套餐）」的文案/图片/视频生成在**任何电脑上都能用**。

## 为什么需要它

- Token Plan 接口官方**不允许浏览器直接调用**（跨域限制），必须经过一个中转服务。
- 原来的中转 `test-xinyang.vercel.app` 跑在境外（Vercel 香港机房），连不上阿里云内地接口，
  所以你会一直在报「连接受限/超时」。
- 把这个中转放到**阿里云函数计算(FC)**（内地节点）后，它和 Token Plan 接口同属阿里云网络，
  连接非常稳定，几秒钟就能返回。这样公司电脑、家里电脑、其他同事电脑都能共用同一个月付套餐额度。

## 部署步骤（照做即可）

### 第 1 步：登录阿里云控制台

打开 https://www.aliyun.com/product/fc 并登录（用你买月付套餐的同一个阿里云账号）。

### 第 2 步：创建函数

1. 点「创建函数」。在「选择最适合你的函数类型」弹窗里，点顶部第二个标签 **「Web 函数」**（不要选 GPU 函数，
   也不要选事件函数/任务函数）。
2. 在这个「创建 Web 函数」表单里依次设置：
   - **函数名称**：随意，例如 `tripmall-proxy`
   - **运行环境**：`自定义运行时 / Python / Python 3.10`（保持默认即可）
   - **代码上传方式**：选 **「通过 ZIP 包上传代码」**
   - **启动命令**：`python3 app.py`
   - **监听端口**：`9000`
   - **执行超时时间**：`600` 秒
   - **最小实例数**：`0`（这样不用的时候不占资源、不扣费；若你想首次更快可填 `1`）
   - 其它保持默认即可。
3. 地域保持 **华北2（北京）**（顶部已选）。
4. 点「创建」，进入函数详情页。

### 第 3 步：上传代码

在函数详情页点 **「代码」** 标签 → 点「上传代码」→ **「上传 ZIP 包」** → 选择 `fc-deploy.zip`。
这个 zip 里应直接包含这几个文件（不要套多余文件夹）：`app.py`、`index.py`、`app_core.py`、
`knowledge_base.json`、`requirements.txt`。上传后点「部署」。

> **依赖**：本包已内置一个用标准库实现的微型 `requests` 兼容层（`requests.py`），所以
> 「千问AI平台 Token Plan」的**文案/海报/视频/知识库/飞书同步无需任何安装就能直接运行**。
> 只有「联网研究 / 解析链接与PPT / 所学的风格画像」这三个辅助功能需要在函数里打开
> **在线编辑器(WebIDE)** 的终端执行 `pip install -t . -r requirements.txt` 后再部署
> （这一步不做也不影响月付套餐的文案/海报/视频）。

### 第 4 步：绑定 HTTP 触发器

1. 新增「触发器」→ 选 **HTTP 触发器**。
2. 鉴权方式：选 **无需鉴权**（这样才能被网页浏览器调用）。
3. 创建后会得到一个**公网访问地址**，形如：

   ```
   https://xxxx.cn-beijing.fcapp.run
   ```

   复制这个地址。

### 第 5 步：自测中转是否可用

在浏览器打开：`<你的地址>/api/health`

例如：

```
https://xxxx.cn-beijing.fcapp.run/api/health
```

如果页面显示 `{"ok": true, ...}` 这样的 JSON，就说明中转已上线。

### 第 6 步：在网站里填中转地址

1. 打开 https://xinyangli-326.github.io/test/ 右上角「AI 设置」。
2. 在「**服务端中转接口地址（月付套餐专用）**」一栏，粘贴上面第 7 步那个地址（末尾**不要带** `/api`）。
3. 保存，页面会自动刷新生效。
4. 之后再用「千问AI平台 Token Plan（月付套餐）」生成文案/海报，就会走你的函数计算中转，不再超时。

> 其它电脑（同事、家里）打开网站后，只要在各自的 AI 设置里填**同一个**中转地址，就能共用月付套餐额度。

## 常见问题

- **保存后还是原来的地址/还是报错**：确认填的是第 7 步能打开 `/api/health` 的地址，不带 `/api`，且保存后页面已刷新。
- **提示 403 Forbidden**：中转接口只放行本网站来源（`xinyangli-326.github.io`）。如果你以后换了
  域名，需在 `fc/index.py` 的 `ALLOWED_ORIGINS` 里加上新域名后重新上传。
- **报「InvalidApiKey」**：说明 Key 不对或不是月付套餐 Key，请检查 AI 设置里填的是 `sk-sp-` 开头的 Token Plan 专属 Key。
- **能打开 /api/health 但生成超时**：把函数超时时间调到 600 秒，并把图片服务商/模型换成套餐内已开通的版本。
- **中转能通但只要一生成就报“连接受限/超时”**：在函数「配置 → 网络」里确认**「允许默认网卡访问公网」是开着的**，
  否则函数无法访问阿里云 Token Plan 接口。
