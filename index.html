Puter 兜底引擎已开始收费。想要接近 Puter 的效果，请选一个大模型：推荐 DeepSeek（deepseek-chat）或硅基流动 DeepSeek-V3、阿里云百炼 qwen-max、Kimi、智谱 GLM-4-Plus（均按量计费、很便宜）。Key 只保存在你浏览器本地，不会上传到任何服务器。选好服务商后点「填入推荐模型」即可。

图片生成（独立配置，海报底图/贴纸用）

阿里月付套餐（Token Plan）配置：图片服务商选「千问AI平台 Token Plan（月付套餐）」，图片 API Key 填 Token Plan 页面里的专属 Key（sk-sp- 开头，创建时只显示一次），图片接口地址默认自动填 https://token-plan.cn-beijing.maas.aliyuncs.com（域名必须含 token-plan，不能填 dashscope）。重要：Token Plan 接口**未开放浏览器跨域**（官方只给服务端工具用），生图/文字会自动走网站自带的中转接口（test-xinyang.vercel.app）——中转后端需已部署且当前网络能访问；若中转不可达，会提示改用「阿里云百炼」（按量，浏览器可直连）或硅基流动。模型 qwen-image-3.0-pro 在套餐内（个人版/团队版都支持），文生图和参考图改图都可用；若报 403 说明该模型不在你的套餐版本，可换 qwen-image-2.0-pro / wan2.7-image。百炼按量用户则选「阿里云百炼」填 sk- 开头 Key；业务空间专属 Key 需在图片接口地址填 {WorkspaceId}.cn-beijing.maas.aliyuncs.com。
